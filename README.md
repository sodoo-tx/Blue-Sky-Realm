# Blue Sky Realm

An offline 3D open-world fantasy RPG that runs in your browser. Pick a species, start in a nest and rise to be its king.

**Play:** open the GitHub Pages link for this repository (Settings → Pages).

- Works on PC, phone and tablet. On a phone, use "Add to Home screen" to install it.
- Everything is saved in your own browser, per account.
- Controls: WASD move · Space jump · F attack · I inventory · M map · F9 item encyclopedia · F10 nest council · = build mode · V fly (Gold rank).
